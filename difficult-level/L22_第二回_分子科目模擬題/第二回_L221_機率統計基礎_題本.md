### 第 12 題［中偏難｜程式與小樣本信賴區間］

某分析者對 9 筆 i.i.d. 常態樣本（母體變異數未知）用以下程式建立平均數信賴區間：

```python
import numpy as np

n = len(x)  # n = 9
se = x.std(ddof=1) / np.sqrt(n)
lo = x.mean() - 1.96 * se
hi = x.mean() + 1.96 * se
```

對這個號稱 95% 的信賴區間，下列何者正確？

B. 只要母體常態，1.96 對任何樣本數都是精確臨界值  
C. `ddof=1` 已使樣本標準差等於母體標準差，因此現有區間為精確 95%  
D. 雙尾 95% 區間應改用 1.645，所以現有區間過寬

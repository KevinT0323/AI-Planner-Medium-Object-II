## L221 機率統計基礎

<a id="l22101"></a>
### L22101 敘述性統計與資料摘要技術【核心】

#### 集中、離散與分位數

| 指標 | 作用／公式 | 常見陷阱 |
|---|---|---|
| 平均數 | `Σx/n`，描述平均位置 | 易受極端值影響 |
| 中位數 | 排序後的中間位置 | 偶數筆時通常取中間兩值的平均 |
| 眾數 | 最常出現的值 | 可用於類別資料，可能不只一個 |
| 全距 | `最大值−最小值` | 只看兩端，易受極端值影響 |
| 變異數 | 平方離差；母體除以 N，樣本估計常除以 `n−1` | 單位為原資料平方，注意題目分母 |
| 標準差 | 變異數的平方根 | 與原資料同單位，不可為負 |
| IQR | `Q3−Q1` | 中間 50% 的跨度，對離群值較穩健 |

- 右偏是右尾較長，平均數通常大於中位數；左偏通常相反。這是常見形態，不能視為所有分布的必然定理。
- 盒鬚圖的盒子為 Q1～Q3，盒內線為中位數；盒長不代表樣本數。
- 常用離群界線為 `Q1−1.5×IQR`、`Q3+1.5×IQR`；超出界線需查證，**不等於錯誤資料或必須刪除**。常見盒鬚延伸到界線內最遠觀測，不一定到最小／最大值。
- P95 是第 95 百分位數，描述尾端位置；不能由平均值代替，也不是所有觀測的上限。分位數插值依工具而異。

#### 一步計算

| 題目 | 正確規則 |
|---|---|
| Z-score | `Z=(x−平均數)/標準差`；`Z=−2` 是低於平均數 2 個標準差 |
| 合併不同大小群組的平均 | `Σ(群組筆數×群組平均)/Σ群組筆數` |
| `Y=aX+b` | 平均 `aμ+b`；標準差 `\|a\|σ`；變異數 `a²σ²` |

例：100 筆平均 200 元、300 筆平均 100 元，整體每筆平均為 `(100×200+300×100)/400=125` 元，不能直接平均成 150 元。若 `Y=(X−50)/10`，X 的平均 70、標準差 15，則 Y 的平均 2、標準差 1.5。

Z 的正負只表示方向；異常與否依題目門檻，如 `|Z|≥3`。標準化本身不會讓偏態資料變成常態。

<a id="l22102"></a>
### L22102 機率分布與資料分布模型【核心】

#### 基本機率

- 補集：`P(Aᶜ)=1−P(A)`。
- 聯集：`P(A∪B)=P(A)+P(B)−P(A∩B)`。
- 條件機率：`P(B|A)=P(A∩B)/P(A)`，須 `P(A)>0`。
- 獨立：`P(A∩B)=P(A)P(B)`；互斥：`P(A∩B)=0`。機率皆非零的互斥事件不獨立。
- Bayes：`P(A|B)=P(B|A)P(A)/P(B)`，須 `P(B)>0`；反向條件機率通常不同。

#### 分布選擇與性質

| 分布 | 題幹線索／條件 | 期望與變異數 |
|---|---|---|
| Bernoulli(p) | 一次成功／失敗，編為 1／0 | `p`；`p(1−p)` |
| Binomial(n,p) | 固定 n 次獨立二元試驗，每次成功機率相同 | `np`；`np(1−p)` |
| Poisson(λ) | 固定時間／空間事件次數；典型模型為獨立增量、穩定發生率 | 平均與變異數皆 `λ` |
| Negative Binomial | 達指定成功次數前的失敗次數；也常用於過度離散計數 | 可容納變異數大於平均數，參數定義依題目 |
| Normal(μ,σ²) | 連續、對稱、鐘形 | `μ`；`σ²` |
| Exponential(rate r) | 固定率 Poisson 過程中的等待時間 | `1/r`；`1/r²` |

- Negative Binomial 的試驗定義同樣假設獨立、成功率固定；題目可能計失敗次數或總試驗次數，先確認定義。
- 計數變異數遠大於平均數，是考慮 Negative Binomial 的線索；仍需排查群組、時段與品質，不能只憑樣本比值確認分布。
- Poisson 的 λ 是**該區間**預期次數：平均每 10 分鐘 2 次，5 分鐘的 λ=1；`P(X=0)=e^(−λ)`，至少一次為 `1−e^(−λ)`。
- 二項例：40 次、`p=0.05`，平均 2、變異數 1.9。固定試驗數與固定時間內事件數要區分。

#### PMF、PDF 與 CDF

| 名詞 | 意義 | 必會判斷 |
|---|---|---|
| PMF | 離散機率質量 `P(X=k)` | 所有可能值機率加總為 1 |
| PDF | 連續機率密度 `f(x)` | 區間機率看面積；密度值可大於 1 |
| CDF | `F(x)=P(X≤x)` | 離散、連續皆適用，單調不減且介於 0～1 |

對**整數型離散 X**，且 k、a、b 為整數：

- `P(X≥k)=1−F(k−1)`；`P(X>k)=1−F(k)`。
- `P(a≤X≤b)=F(b)−F(a−1)`；`P(X=k)=F(k)−F(k−1)`。

對有 PDF 的**連續 X**：`P(X=x)=0`，因此 `P(X≥x)=1−F(x)`，區間端點包含與否不影響機率。不可把整數型公式一律套到連續或非整數離散資料。

#### 常態與近似【理解】

- 常態分布約 68%、95%、99.7% 落在平均數的 1、2、3 個標準差內；偏態資料不能直接套用。
- 二項常態近似需 `np`、`n(1−p)` 足夠大；常見經驗門檻為至少 5 或 10，依題目規定；近似時可用連續性修正。
- 中央極限定理：在獨立同分布、有限變異數等條件下，樣本數夠大時，**樣本平均的抽樣分布**趨近常態；原始資料不會因此變常態。

<a id="l22103"></a>
### L22103 假設檢定與統計推論【核心】

#### 先看分析單位與條件，再選檢定

| 問題 | 常用方法 | 必要判斷 |
|---|---|---|
| 一組平均數與指定值 | 單樣本 t；母體標準差已知可用 Z | 觀測獨立；小樣本 t 通常需近似常態，Z 也需常態或合理大樣本近似 |
| 兩個獨立群組平均數 | 獨立樣本 t | 各組觀測獨立，小樣本各組需近似常態；等變異版本需相等母體變異，不宜假設相等可用 Welch t |
| 同一批對象前後測／自然配對 | 成對樣本 t | 分析每對差值；不同配對間獨立，小樣本要求差值近似常態 |
| 三組以上獨立平均數整體比較 | One-Way ANOVA／F | 傳統版本要求獨立、各組誤差近似常態、等變異；不等變異可考慮 Welch ANOVA |
| 兩個類別變數是否關聯 | 卡方獨立性檢定 | 用列聯表次數；觀測獨立、期望次數足夠；稀疏 2×2 表可考慮 Fisher exact |
| 兩個獨立群組比例 | 雙比例 Z | 各組成功／失敗的期望次數足夠，不能只看總樣本大 |

- ANOVA 顯著表示「至少有一組母體平均不同」，**不表示每組都不同，也不指出哪兩組不同**；必要時做控制多重比較的事後檢定。
- 逐對反覆 t 檢定可能膨脹整體第一類錯誤。卡方期望次數常用 5 作經驗門檻，不能誤看成每格觀測次數。
- Welch 放寬等變異條件，不能自行解決非獨立、極端偏態或離群值問題。
- 同一病人多張影像不是多位獨立病人；樣本多不能補救分析單位或獨立性選錯。

#### H0、p 值與錯誤型態

- H0 是待檢驗的虛無假設，H1 是對立假設；單尾／雙尾與 α 應依問題預先決定，不宜看結果後換方向。
- p 值：**H0 與檢定模型成立時，得到目前或更極端檢定統計量的機率**；雙尾要考慮兩側。
- `p<α` 拒絕 H0；`p≥α` 無法拒絕 H0。p 不是「H0 為真的機率」，也不是效果大小。
- 無法拒絕 H0 不等於證明相同或等效；支持等效需預先定義合理界限及相應檢定。

| 真實情況／決策 | 拒絕 H0 | 未拒絕 H0 |
|---|---|---|
| H0 為真 | 第一類錯誤（Type I），由 α 控制 | 正確決策 |
| H0 為假 | 正確偵測，機率為檢定力 `1−β` | 第二類錯誤（Type II），機率為 β |

α 從 0.05 降至 0.01，拒絕條件更嚴；樣本數、真實效果與方法不變時，第一類錯誤降低，檢定力通常下降。增加樣本數通常有助檢定力，不能消除抽樣偏誤。

#### 信賴區間與實務意義

- 95% 信賴區間：重複抽樣並用同樣方法建構區間，約 95% 的區間涵蓋固定母體參數；不是 95% 資料落在區間內。
- **同一模型、同一雙尾檢定與相符區間方法**下，95% 區間是否排除虛無值，可對照 α=0.05 的顯著性；單尾或不相符方法不能直接對照。
- 虛無值依參數而定：平均差／比例差通常為 **0**；勝算比等比值的無差異值通常為 **1**。不能只背「有沒有包含 0」。
- 標準差描述個體離散；標準誤描述估計量的抽樣不確定性。獨立同分布樣本的平均數標準誤常估為 `s/√n`。
- 樣本增加通常縮小區間；信賴水準提高通常使區間變寬。統計顯著仍須看效果大小、區間與導入成本。

## L222 大數據處理技術

<a id="l22201"></a>
### L22201 數據收集與清理【核心】

#### 先剖析，再決定清理規則

- 檢查型別、單位、合法範圍、缺失比例、重複鍵、標籤品質與來源。`−1` 可能是缺失代碼，`0` 可能是有效觀測，不能一律互換。
- 對稱數值簡單填補可考慮平均；偏態／離群值多可考慮中位數；類別可考慮眾數或「未知」。必要時增加缺失指標。
- 刪除大量缺失列可能改變代表性，填補亦可能縮小變異；缺失與某群組或結果有關時，不能只靠單值填補解決。
- 去重需依事件 ID 或業務鍵；同一人的多筆不同交易不是重複資料。更新紀錄需先釐清保留歷史還是最新版本。

#### 特徵工程與編碼

| 名詞 | 意義／例子 |
|---|---|
| 特徵選擇 | 從原欄位挑選，保留原特徵意義 |
| 特徵衍生 | 既有資料算新欄位，如金額／次數 |
| 特徵轉換 | log、Box–Cox、縮放等改變表示 |
| 特徵離散化 | 連續值切成區間類別 |
| 特徵學習 | 模型自動從文字／影像等學出表示 |

| 編碼 | 適用情況 | 陷阱 |
|---|---|---|
| One-Hot | 無順序類別 | 高基數造成高維；部署需處理未知類別 |
| Ordinal Encoding | 有明確順序，如滿意度 | 順序不代表等距，需檢查模型是否強加距離 |
| Label Encoding | 常用於目標標籤 | 無序特徵編成數字可能製造虛假大小關係 |
| Target Encoding | 用標籤統計表示高基數類別 | 訓練列宜用折外編碼避免自身標籤參與；驗證／測試只套訓練映射 |

月份、星期等循環特徵可用正弦／餘弦成對表示，讓週期末端與起點相鄰；不是所有日期欄位都適合普通有序距離。

#### 縮放：改變表示不等於變常態

| 方法 | 常見公式 | 限制 |
|---|---|---|
| Standardization | `(x−μ_train)/σ_train` | 非常數訓練欄位約平均 0、標準差 1；受離群值影響，不限於 0～1 |
| Min-Max | `(x−min_train)/(max_train−min_train)` | 訓練值常映到 0～1；對極端值敏感，新值可超出範圍 |
| RobustScaler | `(x−median_train)/IQR_train` | 對少數極端值較穩健；不會自動刪除離群值 |

PCA、KNN、K-means 等受量尺影響，通常先適當縮放；決策樹通常沒有同樣的距離縮放需求。零變異欄位與分母為零需依工具處理。

#### 資料洩漏：切分邊界內才學參數

**先保留獨立測試集；交叉驗證時，每一折也只用該折訓練部分 fit。**

| 常見洩漏 | 正確做法 |
|---|---|
| 全資料先填補、縮放、PCA、選特徵再切分 | 各訓練集合內擬合，驗證／測試沿用參數 |
| 全部開發集標籤先選特徵，再 CV | 選特徵與模型放入 Pipeline，每折重新 fit |
| 切分前 SMOTE／增強 | 先切原始資料，再僅處理訓練部分；測試保留實際分布 |
| target encoding 含訓練列自身標籤 | 當輪訓練部分內再做折外編碼／cross-fitting |
| 事後結果、未來實際值當特徵 | 僅用預測當下可得資訊 |
| 同一人或原圖近似版本跨集合 | 依人／設備／原始樣本群組切分 |
| 反覆看測試成績選模型、參數或門檻 | 用驗證集／CV 做選擇，測試留作最終評估 |

Pipeline 可避免其中的前處理跨 CV 折擬合，**不會自動修正錯誤時間特徵、群組切分或測試集調參**。

大 CSV 讀不進記憶體，用 `pd.read_csv(..., chunksize=...)` 逐批處理；`nrows` 只讀部分資料。最後把全部批次合併回記憶體，仍可能超出容量。

### L22202 數據儲存與管理【核心】

#### ACID 與資料庫選型

| ACID | 核心意思 | 情境 |
|---|---|---|
| Atomicity 原子性 | 交易全成或全敗 | 扣款、加款共同提交或回滾 |
| Consistency 一致性 | 維持已定義完整性規則 | 遵守約束；不是所有副本立即相同的同義詞 |
| Isolation 隔離性 | 並行交易依隔離層級避免不當干擾 | 同時搶位；隔離程度依設定 |
| Durability 持久性 | 已提交結果在承諾的故障復原條件下保存 | 回覆提交成功後斷電，復原仍有訂單 |

| 需求 | 常見選擇 |
|---|---|
| 結構化關聯、交易與完整性約束 | 關聯式資料庫 |
| 彈性、巢狀、半結構化欄位 | 文件型資料庫 |
| 高維向量相似搜尋 | 向量資料庫／向量索引 |
| 節點、邊與多跳路徑 | 圖形資料庫 |
| 大量分析、彙總與欄位掃描 | 資料倉儲、欄式儲存 |
| 多來源原始與處理後資料 | Data Lake；仍需治理與分析引擎 |

- 依工作負載搭配儲存；不能把 NoSQL 一概視為沒有交易，也不能把向量搜尋當成付款／庫存交易。
- Parquet 等欄式格式利於只讀少數欄位與壓縮；日期分區可排除不相關日期。兩者減少不同方向的讀取量。
- **Sharding** 分散不同資料列，提高容量與負載能力；分片鍵不良仍有熱點。**Replication** 保存副本，提高可用性與容錯；副本不等於完整備份策略。
- Feature Store 共用特徵定義、版本與產製方式，降低重複開發及訓練／服務不一致。

#### 合併資料先看鍵與粒度

- `inner` 留共同鍵；`left` 留左表紀錄及匹配；`outer` 留任一表出現的鍵。
- **left join 不保證左表列數不變**：右表同鍵有兩列，左表該訂單可能出現兩次，使金額加總重複。
- 會員、訂單、明細的粒度不同；查訂單數不能直接數明細列。預期多對一可用 `validate='many_to_one'` 檢查，再依業務規則處理重複鍵。

<a id="l22203"></a>
### L22203 數據處理技術與工具【核心】

| 概念／工具 | 用途與判斷 |
|---|---|
| Batch 批次處理 | 定期處理一批資料，適合日報與大量離線計算 |
| Stream 串流處理 | 持續處理事件，適合低延遲監控／告警 |
| ETL／ELT | ETL 先轉換再載入；ELT 先載入目標儲存再轉換 |
| Pandas | 單機表格清理、聚合，受記憶體限制 |
| Spark | 分散式平行處理、水平擴展與容錯 |
| 訊息代理（如 Kafka） | 傳遞與保留事件供下游處理，不自動完成所有分析 |

- 即時 IoT：感測器 → 訊息代理／邊緣處理 → 串流處理；完整歷史另存資料湖供回放與訓練。
- 重試可能重複送達，用穩定事件 ID 去重；事件時間與接收時間可能不同，晚到資料需有更新規則。
- Spark 由 executor 計算局部統計再彙總，避免將巨量資料 `collect()` 到 driver 導致記憶體不足。
- 全局平均為 `Σ局部 sum / Σ局部有效 count`，不可直接平均不同大小分片／批次的平均。分子略過缺失時，分母也應對應有效值。
- Approximate Quantile 在容忍誤差下估算分位數，適合大量資料，不等於保證精確結果。

## L223 大數據分析方法與工具

<a id="l22301"></a>
### L22301 統計學在大數據中的應用【核心】

#### 抽樣、相關與組成效果

| 方法／概念 | 判斷重點 |
|---|---|
| 隨機抽樣 | 母體、抽樣框、分析單位要符合問題；問會員不能直接抽訂單再去重 |
| 分層抽樣 | 分層後抽樣確保重要群體代表性；合併結果需注意權重 |
| Pearson | 線性關係，對離群值敏感；零相關不保證沒有非線性關係 |
| Spearman | 以排名衡量單調關係，可處理單調非線性關係 |
| Kendall | 以一致／不一致配對衡量排名關聯 |
| 辛普森悖論 | 群組占比不同，整體方向可能與各層方向相反 |

相關不等於因果；大量資料可降低部分抽樣不確定性，不能自動消除偏誤、混雜或非獨立觀測的問題。

#### 降維、轉換與分位數【理解】

- PCA 找最大變異方向，主成分彼此正交；一般 PCA 不用標籤，保留高變異**不保證保留分類訊號**。不同量尺通常先標準化，成分數需配合驗證。
- SVD 可分解長方形矩陣；Truncated SVD 常用文字稀疏矩陣與 LSA，通常不需要像一般 PCA 一樣先中心化稀疏矩陣。
- Box–Cox 要求嚴格正值，常用正值偏態資料；不能直接處理 0／負值，也不保證都變常態。
- Quantile Regression 估計條件分布特定分位數，如條件 P95；Approximate Quantile 是快速估算資料分位數，兩者不同。

#### 時間序列：可得時間比日期名稱重要

- 預測未來以時間切分或 walk-forward validation；每輪前處理只學當輪過去資料。
- lag、rolling、星期、月份、節日是常見特徵。預測當日銷量通常先 `shift(1)` 再取過去窗口，並先依實體與時間排序。
- 未來日期的已排定促銷、當時發布的天氣預報可用；事後實際天氣、未來銷量、後來才決定的促銷不可用。

<a id="l22302"></a>
### L22302 常見的大數據分析方法【核心】

#### 任務與演算法

| 任務 | 常見方法／目的 |
|---|---|
| 監督式分類 | Logistic Regression、tree、KNN 等，預測離散標籤 |
| 監督式迴歸 | 線性迴歸等，預測連續值 |
| 非監督式分群 | K-means、DBSCAN，不需既有類別標籤 |
| 降維 | PCA、SVD，壓縮表示 |
| 關聯規則 | 找共同出現模式 |
| 異常偵測 | 找罕見或偏離一般模式的觀測 |

- K-means 先指定 k，反覆「分配到最近中心 → 更新群平均」；適合較緊密群組，對尺度與離群值敏感。
- DBSCAN 依密度、ε、min_samples 成群，可找部分不規則形狀並標記雜訊，不必預先指定群數；不同密度／高維仍難設定鄰域。
- KNN 用近鄰分類投票或迴歸平均，k 是鄰居數；K-means 的 k 是群數。高維距離集中可能影響這些距離型方法。

#### 關聯規則 A→B

| 指標 | 公式 | 分母 |
|---|---|---|
| support | `P(A∩B)` | 全部交易 |
| confidence | `P(B\|A)=P(A∩B)/P(A)` | 含 A 的交易 |
| lift | `P(B\|A)/P(B)` | 再對比 B 的基準發生率 |

例：10,000 筆，A 有 2,000、B 有 1,000、共同 400：support=0.04、confidence=0.20、lift=2。lift `>1` 為正向關聯、`=1` 表示對該 A/B 的共現符合獨立、`<1` 為負向關聯；不代表因果。A→B 與 B→A 的 confidence 通常不同。

#### 分類評估：先指定正類與分母

| 真實／預測 | 預測正 | 預測負 |
|---|---|---|
| 真實正 | TP | FN（漏報） |
| 真實負 | FP（誤報） | TN |

| 指標 | 公式 | 回答的問題 |
|---|---|---|
| Accuracy | `(TP+TN)/(TP+FP+FN+TN)` | 全部預測中多少正確 |
| Precision | `TP/(TP+FP)` | 警報中有多少是真的 |
| Recall／TPR | `TP/(TP+FN)` | 真正正例抓到多少 |
| Specificity／TNR | `TN/(TN+FP)` | 真正負例排除多少 |
| FPR | `FP/(FP+TN)` | 真正負例中多少誤報 |
| F1 | `2PR/(P+R)=2TP/(2TP+FP+FN)` | precision、recall 的調和平均，不使用 TN |

- 正例若占 0.2%，全預測負仍有 99.8% accuracy，但 recall=0；需看少數類、PR 指標及成本。
- ROC：橫軸 FPR、縱軸 TPR；PR：橫軸 recall、縱軸 precision。負類多時低 FPR 仍可能是大量 FP，PR 更直觀呈現稀少正類的警報品質。
- ROC-AUC 是跨門檻排序能力，**不等於機率校準或業務門檻**。同一批分數只改決策門檻不改 AUC；嚴格遞增轉換保留排序，但可改變機率與固定門檻判斷。
- macro F1：各類 F1 等權平均；weighted F1：依各類真實樣本數（support）加權；micro F1：先合併各類 TP／FP／FN 再算。高 weighted F1 仍可能掩蓋少數類很差。

#### 門檻與不平衡處理

- 固定模型與資料，降低正類門檻使 TP、FP 不減，recall、FPR 不減；**precision 變化方向不保證**。提高門檻通常用於減少誤報，仍須實際驗證指標。
- 門檻不必固定 0.5；在驗證資料依漏報成本、誤報成本及覆核容量選定，再用獨立測試集評估。
- 簡單成本：`C_FN×FN+C_FP×FP`；待審量：`TP+FP`。最低成本方案仍需滿足審查上限。
- Oversampling 增少數類，undersampling 減多數類；SMOTE 依訓練近鄰合成樣本。都只做在每折訓練部分，驗證／測試保留目標分布。
- Class weight／cost-sensitive learning 改變損失權重，不保證 recall 必然提高；常見 balanced 類別權重為 `N/(K×n_class)`。

#### 迴歸評估與驗證切分

| 指標 | 公式（誤差 `e=y−ŷ`） | 特性 |
|---|---|---|
| MAE | `Σ\|e\|/n` | 同目標單位，較不放大個別大誤差 |
| MSE | `Σe²/n` | 平方單位，對大誤差敏感 |
| RMSE | `√MSE` | 同目標單位，仍對大誤差敏感 |

| 切分 | 適用情境 | 邊界 |
|---|---|---|
| Stratified K-Fold | 獨立分類樣本，維持近似類別比例 | 不自動避免同人或時間洩漏 |
| Group Split | 部署對象是新病人／客戶／設備 | 同群組不可跨集合 |
| Time Split／walk-forward | 預測未來 | 過去訓練、之後驗證，特徵仍需遵守可得時間 |

訓練集學參數，驗證集／CV 選模型、超參數與門檻，測試集作最終獨立評估。群組與時間限制同時存在時需同時滿足，不能只靠分層切分。

<a id="l22303"></a>
### L22303 數據可視化工具【核心】

| 問題 | 適合圖形 | 注意 |
|---|---|---|
| 時間趨勢 | 折線圖 | 保持時間順序 |
| 類別數值比較 | 長條圖 | 通常用共同零基線 |
| 單變數分布 | Histogram、box plot | 分箱影響外觀；盒鬚圖不顯示完整密度 |
| 兩連續變數關係 | Scatter plot | 不等於因果 |
| 大量散點重疊 | Hexbin／2D density | 聚合一般點，重要罕見點另層完整顯示 |
| 多變數相關 | Correlation heatmap | 色階標示方向與強度 |
| 多群時間比較 | Small multiples（分面小圖） | 比較絕對大小時共用刻度與單位 |

- Histogram 組距不等時，密度高度為 `該箱筆數/(總筆數×組距)`，**柱面積**才是比例。
- 長條圖截斷 y 軸會誇大長度差異；折線圖不必一律從 0 開始，但尺度與標籤須清楚。
- 氣泡圖若以面積表示數值，數值 4 倍對應半徑 2 倍，不能把半徑也放大 4 倍。
- 比較比率需看分母與不確定性；2/10 與 100/1,000 的樣本規模不同。百分點與百分比變化也不同。
- 3D、陰影等 non-data ink 可能妨礙判讀。Tufte 的資料密度關心有限空間內的有效資訊，同時維持可讀性，並非越擠越好。
- Matplotlib 提供基本繪圖控制，Seaborn 方便統計圖，互動式工具適合篩選探索；先按問題選圖，再選工具。

## L224 大數據在人工智慧之應用

<a id="l22401"></a>
### L22401 大數據與機器學習【理解】

- 常見 5V：Volume（量）、Velocity（速度）、Variety（多樣）、Veracity（可信／品質）、Value（價值）。更多資料不保證品質、代表性或成效。
- 過擬合常見於訓練好、未見資料差；要看獨立驗證。資料增強須保留標籤，先切原始樣本，再只增強訓練資料。
- 大批次通常提升吞吐、降低梯度噪音，仍需調整學習率並驗證泛化。一般資料平行設定：`global batch=每裝置 batch×裝置數×累積步數`。
- 小檔案太多增加開檔與 metadata 成本；GPU 等資料時檢查載入、prefetch、並行 worker、快取與儲存吞吐。
- Feature Store 共用定義與版本，降低 training-serving skew，不能自動保證定義正確或沒有洩漏。
- 資料漂移為 `P(X)` 改變；概念漂移為 `P(Y|X)` 改變。輸入分布改變不等於已證明效能下降，需查資料品質並以新標籤評估。

<a id="l22402"></a>
### L22402 大數據在鑑別式 AI 中的應用【核心】

- 鑑別式方法直接建模 `P(Y|X)` 或決策邊界；Logistic Regression 名稱有 regression，典型用途仍是分類；Linear Regression 典型用途是連續值預測。
- 生成式分類方法可建模 `P(X|Y)` 與 `P(Y)` 再推得分類結果；**有標籤、可分類或輸出機率，均不足以單獨判斷是鑑別式或生成式**。
- 決策樹以特徵切點反覆分割；Gini 不純度為 `1−Σp_class²`。分割後子節點需按各自樣本數加權；純節點 Gini=0。
- KNN 等權分類看近鄰票數；距離加權加總各類權重，不一定選票數最多者。k 與量尺影響結果。
- 應用決定評估：怕漏報看 recall 與成本，覆核有限同看 precision 與待審量；新病人部署依病人切分，未來預測依時間切分。
- 排序、機率校準與門檻決策不同：AUC 高不保證預測 0.8 的群體約 80% 發生，也不保證 0.5 門檻合適。

<a id="l22403"></a>
### L22403 大數據在生成式 AI 中的應用【理解】

| 方法／概念 | 目標 | 易混淆點 |
|---|---|---|
| Positional Encoding／位置表示 | 提供 token 順序 | 不等於 padding 或 causal mask |
| Padding mask | 排除補齊符號影響 | 不是加入順序 |
| Causal mask | 自回歸預測時阻止看後續 token | 不是處理補齊符號 |
| RAG | 檢索外部知識再生成，適合常更新、需來源的知識 | 檢索前／時套權限，仍可能幻覺 |
| 微調 | 改變行為、格式、風格或任務能力 | 不是每日更新事實與逐文件權限的替代品 |
| Text-to-SQL | 自然語言轉 SQL，由資料庫查詢／聚合 | SQL 可執行不代表商業口徑正確 |

- 大規模語料仍需清理、去重、品質與權利確認、正確切分；文件近似版本跨評估集可能高估能力。
- RAG：文件切分 → embedding／索引 → 檢索 → 必要時 rerank → 授權證據進上下文 → 回答與引用。
- 證據已在候選但沒進上下文，可改善排序；根本沒被檢索到，需查索引與召回。分別驗證檢索與最終回答。
- Text-to-SQL 要提供 schema、關聯、指標定義與限制，注意訂單／明細粒度、去重、日期邊界及查詢權限。

<a id="l22404"></a>
### L22404 大數據隱私保護、安全與合規【核心定義】

| 技術／風險 | 核心概念 | 保證邊界 |
|---|---|---|
| 匿名化 | 在合理可用方法與資訊下難以再識別 | 移除姓名不足以確認匿名 |
| 假名化 | 以代碼替代直接身分 | 仍可能由映射／外部資訊再識別 |
| k-anonymity | 每組相同準識別特徵至少 k 筆 | 不要求敏感值多樣；同質群仍可揭露屬性 |
| 差分隱私 | 隨機化限制單一個體加入／移除對輸出分布的影響 | 依參數可量化，有隱私／效用取捨 |
| 同態加密 | 密文上運算，解密得對應結果 | 不自動保護公開結果中的資訊 |
| 聯邦學習 | 各方本地訓練後聚合更新 | 不集中原始資料不等於完全隱私 |
| 安全聚合 | 依協定假設，取得合計而非個別更新 | 需明確參與者、串通、掉線假設 |
| Membership Inference | 判斷某筆是否在訓練集 | 未公開原始資料仍可能由模型輸出揭露 |

- 固定雜湊通常仍是假名化；年齡、居住地等準識別特徵可與外部資料聯合再識別。
- 加密、匿名化與差分隱私解決不同問題，不能互相替代；差分隱私多次發布需考慮預算，核心階段不必做複雜組合手算。
- 合規需合法蒐集／利用依據、目的限制、資料最小化、保存期限、存取控制與稽核；一項技術不等於全面合法。

## L221 機率統計基礎

### L22101 敘述性統計與資料摘要技術【核心】

#### 集中與離散

| 指標 | 作用 | 常見陷阱 |
|---|---|---|
| 平均數 | 描述平均位置 | 易受極端值影響 |
| 中位數 | 排序後的中間位置 | 右偏、有離群值時通常比平均數穩健 |
| 變異數 | 平均平方離差 | 單位是原資料的平方 |
| 標準差 | 描述典型離散程度 | 與原資料同單位 |
| IQR | `Q3-Q1` | 對離群值較穩健 |

- 右偏：右側尾巴較長，通常 `平均數 > 中位數`。
- 左偏：左側尾巴較長，通常 `平均數 < 中位數`。
- 盒鬚圖的盒子表示 Q1～Q3；盒子越長代表中間 50% 越分散。
- 常見離群界線：`Q1-1.5IQR` 與 `Q3+1.5IQR`。

#### Z-score

`Z=(x-平均數)/標準差`

- `Z=2`：數值高於平均數 2 個標準差。
- `Z=-2`：數值低於平均數 2 個標準差。
- 是否算異常需看題目門檻，例如 `|Z|≥3`。
- Z 為負不代表資料無效，只代表低於平均數。

#### 缺失值基本判斷

- 數值近似對稱：簡單題常考平均數填補。
- 明顯偏態或有離群值：中位數通常較穩健。
- 類別欄位：可考慮眾數或建立「未知」類別。
- 填補不是萬靈丹；應先檢查缺失比例與缺失是否集中在特定群組。

### L22102 機率分布與資料分布模型【核心】

| 分布 | 題幹線索 |
|---|---|
| Bernoulli | 一次成功／失敗 |
| Binomial | 固定 n 次獨立試驗中的成功次數 |
| Poisson | 固定時間／空間內事件次數；獨立且平均發生率穩定 |
| Negative Binomial | 計數資料的變異數明顯大於平均數 |
| Normal | 連續、對稱、鐘形分布 |
| Exponential | Poisson 過程中的等待時間 |

#### CDF 與 PMF

- `PMF(k)=P(X=k)`：離散變數恰好等於 k 的機率。
- `CDF(k)=P(X≤k)`：累積到 k 的機率，包含端點。
- `P(X≥k)=1-P(X≤k-1)`。
- 「至少、超過、至多、少於」先翻成數學不等式再算。

#### 常態近似

二項分布樣本數夠大，且 `np`、`n(1-p)` 都不太小時，可考慮常態近似。考題通常重在辨識條件，不要求複雜推導。

### L22103 假設檢定與統計推論【核心】

#### 檢定選擇

| 問題 | 常用方法 |
|---|---|
| 一組平均數與指定值比較 | 單樣本 t 檢定；母體標準差已知時可考慮 Z 檢定 |
| 兩個獨立群組平均數 | 獨立樣本 t 檢定 |
| 同一批對象前後測 | 成對樣本 t 檢定 |
| 三組以上平均數 | One-Way ANOVA／F 檢定 |
| 兩個類別變數是否關聯 | 卡方獨立性檢定 |
| 兩組比例是否不同 | 雙比例 Z 檢定 |

#### 必會解讀

- p 值：假設 H0 成立時，得到目前或更極端結果的機率。
- `p<α`：拒絕 H0；`p≥α`：無法拒絕 H0。
- 無法拒絕 H0 不等於證明兩者相同。
- 第一類錯誤：H0 為真卻拒絕，機率以 α 控制。
- 第二類錯誤：H0 為假卻未拒絕，機率為 β。
- 檢定力：`1-β`。
- α 從 0.05 降至 0.01，判定顯著更嚴格，第一類錯誤降低；其他條件不變時，第二類錯誤可能上升。
- 95% 信賴區間若包含虛無值 0，雙尾 5% 檢定通常不顯著。
- 統計顯著不等於實務重要，還要看效果大小。

## L222 大數據處理技術

### L22201 數據收集與清理【核心】

#### 特徵工程名詞

- 特徵選擇：從現有欄位中挑選。
- 特徵衍生：用既有欄位算出新欄位，例如金額／次數。
- 特徵轉換：log、Box–Cox、標準化等改變表示方式。
- 特徵離散化：把連續值切成區間類別。
- 特徵學習：由模型自動從文字、影像等學出表示。

#### 編碼

| 方法 | 適用情況 | 風險 |
|---|---|---|
| One-Hot | 無順序類別 | 高基數會維度爆炸 |
| Ordinal Encoding | 有明確順序，如滿意度等級 | 順序設定錯誤會誤導模型 |
| Label Encoding | 常用於標籤；若當特徵使用要小心 | 無序類別可能產生虛假順序 |
| Target Encoding | 高基數類別 | 必須只在訓練 fold 內估計，否則洩漏 |

#### 縮放

- Standardization：常轉成平均 0、標準差 1。
- Min-Max：常轉到 0～1，容易受極端值影響。
- RobustScaler：以中位數、IQR 為基礎，較適合有離群值的資料。
- PCA 與距離型方法通常需注意不同欄位量尺。

#### 資料洩漏

正確原則：**先切分，再只用訓練資料 fit。**

以下都可能洩漏：

- 用全資料計算縮放、填補、特徵選擇參數。
- 在切分前執行 SMOTE。
- 用未來資料建立歷史預測特徵。
- 同一病人、使用者或設備的高度相似資料跨到訓練與測試。

#### 大檔案

Pandas 處理超過記憶體的 CSV，可使用 `pd.read_csv(..., chunksize=...)` 逐批處理；限制 `nrows` 只會讀取部分資料，不等於完成全量分析。

### L22202 數據儲存與管理【核心】

#### ACID

- Atomicity：交易全部成功或全部失敗。
- Consistency：交易前後符合資料規則與完整性限制。
- Isolation：並行交易不應產生不當干擾。
- Durability：已提交結果在故障後仍能保留。

#### 資料庫選擇

| 需求 | 常見選擇 |
|---|---|
| 強交易、結構化關聯 | 關聯式資料庫 |
| 彈性、巢狀、半結構化欄位 | 文件型資料庫 |
| 高維向量相似搜尋 | 向量資料庫／向量索引 |
| 節點與關係查詢 | 圖形資料庫 |
| 大量分析掃描 | 資料倉儲、欄式儲存 |
| 保存多來源原始與處理後資料 | Data Lake |

- Sharding：把資料列水平分散至多個節點，提高橫向擴展與負載能力。
- Replication：保存副本以提高可用性與容錯，與 sharding 的目的不同。
- Feature Store：共用版本化特徵，減少重複開發與訓練／服務不一致。

### L22203 數據處理技術與工具【核心】

- 即時 IoT 常見流程：感測器 → 訊息代理／邊緣處理 → 串流處理 → 資料湖／資料庫。
- Spark 等分散式系統應讓 executor 計算局部統計後彙總。
- 不要把巨量資料 `collect()` 到 driver，容易記憶體不足。
- 分散式運算的核心目的包括水平擴展、平行處理與容錯。
- Approximate Quantile 是在可容忍誤差內快速估算分位數，適合大量資料與即時分析。

## L223 大數據分析方法與工具

### L22301 統計學在大數據中的應用【核心】

#### 相關係數

- Pearson：衡量線性關係，對離群值較敏感。
- Spearman：把數值換成排名後算相關，可處理單調但非線性關係。
- Kendall：以一致／不一致配對為基礎，適合排名與較小樣本情境。
- 相關不等於因果。

#### 降維與轉換

- PCA：找最大變異方向；不同量尺通常先標準化。
- SVD：可分解長方形矩陣；Truncated SVD 常用於文字稀疏矩陣與 LSA。
- Box–Cox：常用於正值右偏資料的分布轉換。
- Quantile Regression：關心條件分布特定分位數，適合尾端風險。

#### 時間序列

- 不應隨機打散未來與過去。
- 依時間切分，或使用 walk-forward validation。
- 常見特徵：lag、rolling statistics、星期、月份、節日。
- 建立特徵時不能使用預測時間點之後的資料。

### L22302 常見的大數據分析方法【核心】

| 任務 | 典型方法 |
|---|---|
| 預測連續值 | 線性迴歸等迴歸模型 |
| 預測二元／多類別標籤 | Logistic Regression、tree 等分類模型 |
| 無標籤分群 | K-means、DBSCAN |
| 降維 | PCA、SVD |
| 罕見模式 | 異常偵測 |

#### 分群

- K-means：事先指定 k，以群中心表示群組；對尺度與離群值敏感。
- DBSCAN：依密度形成群組並標記雜訊；高維時距離集中，ε 難以設定。

#### 關聯規則

- support：`P(A∩B)`。
- confidence：`P(B|A)`。
- lift：`P(B|A)/P(B)`。
- lift `>1` 表示正向關聯，`=1` 表示近似獨立，`<1` 表示負向關聯；不代表因果。

#### 不平衡分類

- Accuracy 在少數類極少時可能嚴重誤導。
- Precision：`TP/(TP+FP)`，預測為正的案例中多少是真的。
- Recall：`TP/(TP+FN)`，真正正例中抓到多少。
- F1：precision 與 recall 的調和平均。
- ROC：橫軸 FPR、縱軸 TPR／Recall。
- 若不能漏掉正例，優先提高 recall，通常會降低 threshold，但誤報也可能增加。
- SMOTE 只在訓練 fold 內執行。
- Class weight／cost-sensitive learning 用損失權重提高少數類錯誤代價。

#### 驗證切分

- Stratified K-Fold：讓每折類別比例近似一致。
- Group Split：同一病人／客戶／設備不得跨集合。
- Time Split：預測未來時維持時間順序。

### L22303 數據可視化工具【核心】

| 問題 | 適合圖形 |
|---|---|
| 時間趨勢 | 折線圖 |
| 類別數值比較 | 長條圖 |
| 單一變數分布 | Histogram、box plot |
| 兩個連續變數關係 | Scatter plot |
| 大量散點重疊 | Hexbin／2D density |
| 多變數相關係數 | Correlation heatmap |

- 長條圖截斷 y 軸容易誇大差異。
- 3D、陰影與過多裝飾可能造成視覺誤導。
- Tufte 的資料密度強調在有限空間呈現更多有效資訊，同時保持可讀性。
- 罕見但重要事件不能只靠低比例隨機抽樣；可將一般點聚合，重要點另層完整呈現。

## L224 大數據在人工智慧之應用

### L22401 大數據與機器學習【次要但要懂】

- 大批次通常提高硬體吞吐、降低梯度噪音，但可能需要調整學習率並注意泛化。
- 大量小檔案會增加 metadata 與開檔成本，可整理成適中且可切分的檔案。
- GPU 等資料時，優先改善資料載入、prefetch、並行 worker 與快取。
- Feature Store 的重點是特徵共用、版本管理與訓練／服務一致性。

### L22402 大數據在鑑別式 AI 中的應用【核心】

- 分類預測離散標籤；迴歸預測連續數值。
- Logistic Regression 適合分類並可輸出機率；Linear Regression 適合連續值。
- 極不平衡資料不能只看 accuracy。
- 門檻依業務成本、recall、precision 與人工覆核容量調整，不必固定 0.5。
- 新病人部署要依病人切分；未來預測要依時間切分。
- 排序能力與機率校準不同：AUC 高不代表預測 0.8 的事件真的約 80% 發生。

### L22403 大數據在生成式 AI 中的應用【次要但要懂】

- Transformer positional encoding：加入 token 順序資訊。
- RAG：適合知識常更新、答案需附來源與權限控管的情境。
- Text-to-SQL：將自然語言轉成 SQL，再交由資料庫精確執行聚合與查詢。
- 微調較適合改變模型行為、風格或任務能力，不適合反覆灌入每天更新的事實。

### L22404 隱私保護、安全與合規【核心定義】

| 技術／風險 | 核心概念 |
|---|---|
| 匿名化 | 在合理條件下難以再識別 |
| 假名化 | 以代碼替代身分，但仍可能透過映射或外部資訊再識別 |
| k-anonymity | 每組相同準識別特徵至少有 k 筆 |
| 差分隱私 | 以隨機化限制單一個體對輸出的影響，提供可量化隱私保證 |
| 同態加密 | 可在密文上運算，解密後得到對應結果 |
| Membership Inference | 判斷某筆資料是否曾出現在訓練集中 |

- 固定雜湊識別碼通常仍屬假名化，不自動等於匿名化。
- 加密、匿名化與差分隱私解決的問題不同，不能互相替代。
- 個資利用還需注意目的限制、資料最小化、存取控制與稽核。

## 正式考試常見 Python 閱讀

```python
# 基本摘要與缺失值
df['sales'].describe()
df.isna().sum()

# 條件篩選
df[df['category'] == 'Book']['price'].mean()

# 分組加總與前幾名
df.groupby('customer_id')['revenue'].sum().nlargest(5)

# 只保留兩表皆有的鍵
pd.merge(orders, customers, on='customer_id', how='inner')

# 大檔案分批讀取
pd.read_csv('events.csv', chunksize=5000)

# 訓練與轉換
scaler.fit(X_train)
X_train_scaled = scaler.transform(X_train)
X_test_scaled = scaler.transform(X_test)

model.fit(X_train, y_train)
pred = model.predict(X_test)
```

必須理解：

- `sum()`、`mean()`、`count()` 的問題不同。
- `groupby` 後要依題目選正確聚合。
- `inner` 只保留兩表都有的鍵；`outer` 保留任一表出現的鍵。
- `fit` 學參數，`transform` 套用參數，`fit_transform` 同時做兩者。
- Pandas `'Int64'` 是可保留缺失值的 nullable integer。
- weighted F1 是各類別 F1 依真實樣本數加權。

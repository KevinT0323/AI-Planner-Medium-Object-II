# 科目二真題校準與複習優先級

## 先分清三種資訊

## 官方規則與歷屆觀察

- 115 年簡章規定中級每科 50 題、90 分鐘、單選題；科目二包含程式相關題型。
- 依既有整理的人工判讀，114 年約 12 題、115 年第 39～50 題被歸為程式相關題；目前尚未附逐題分類對照，這項估計僅作複習參考。
- 程式題重點是「讀懂」，不是從零撰寫完整程式。
- 主要工具為 Pandas、基本 Scikit-learn，以及少量 Seaborn／SciPy／虛擬程式碼。
- 理論題常包裝成企業或模型情境，但多數答案仍落在一個清楚的核心概念。
- 同一核心會跨年度重複變形，例如 Z-score、Poisson、編碼、資料不平衡、資料洩漏、視覺化與 Pandas。

12／50＝24% 是上述人工判讀的估計，**簡章未規定程式題固定比例**。短程式與虛擬程式碼的計數邊界會影響歸類，不能把這項估計當作官方頻率統計。

<a id="priority-a"></a>

## A 級：最優先，應先拿穩的分數

初次安排可投入約 70% 複習時間；與 B 級 20%、C 級 10% 合計 100%。這是時間配置範例，若基礎錯題仍多，應把 C 級時間移回 A 級。

### 統計與機率

- 平均數、中位數、標準差、四分位數、IQR、盒鬚圖、偏態。
- Z-score：公式、正負方向、距平均幾個標準差、異常門檻。
- CDF／PDF 的基本意義；`pmf`、`cdf` 的直觀判讀；整數型與連續型機率的端點差異。
- Poisson：固定時間內、事件獨立、平均發生率穩定；變異明顯大於平均時想到 Negative Binomial。
- 常態、二項與 Bernoulli 的基本使用情境。
- t 檢定：單樣本、獨立樣本、成對樣本的情境辨識與前提；獨立兩組不等變異時可用 Welch t。
- 三組以上平均數比較：One-Way ANOVA／F 檢定。
- p 值、顯著水準、信賴區間、第一與第二類錯誤；不顯著不代表等效。

### 資料前處理

- 缺失值：右偏資料常優先考慮中位數；知道刪除與填補的取捨。
- Standardization 與 Min-Max normalization 的差異。
- 離群值多時的 RobustScaler。
- Label／Ordinal／One-Hot Encoding 的適用條件與虛假順序風險。
- 特徵選擇、特徵衍生、特徵轉換、離散化的差別。
- 所有會學到資料參數的處理只能在訓練資料 fit；交叉驗證時在每個訓練 fold 內做前處理、特徵選擇與 SMOTE。
- 大 CSV 無法載入記憶體：`read_csv(chunksize=...)`。

### 大數據與資料庫

- ACID 四項，尤其 Atomicity。
- Sharding 是水平切分以提升擴展性與負載分散。
- 依需求選資料庫：關聯式、文件型、向量資料庫、圖形資料庫。
- 即時 IoT 流程：訊息傳遞／邊緣或串流處理／資料湖保存。
- Spark 在 executor 做局部統計再彙總；避免把巨量資料 `collect()` 回 driver。
- 資料湖、分散式處理與基本 pipeline 觀念。

### 分析方法與評估

- 分類、迴歸、分群、降維與異常偵測的任務辨識。
- Logistic Regression、K-means、KNN、PCA／SVD 的基本用途。
- 關聯規則：support、confidence、lift 的定義與簡單計算。
- 類別不平衡：accuracy 陷阱、precision、recall、F1、ROC／PR；極少數類不能只看 accuracy 或整體 weighted F1。
- SMOTE／oversampling、class weight／cost-sensitive learning 的基本作用。
- Stratified K-Fold 與 Group Split 的使用時機。
- 門檻降低通常提高 recall、同時增加誤報。

### 視覺化

- 時間趨勢用折線圖；相關矩陣用 heatmap；類別比較用長條圖。
- y 軸截斷會放大差異；3D 與裝飾可能誤導。
- Tufte 的資料密度與 non-data ink 基本觀念。
- scatter／hexbin、box plot、histogram 的適用問題。

### Python 閱讀

一定要能讀懂：

```python
df['col'].describe()
df['col'].isna().sum()
df[df['Category'] == 'A']['Revenue'].mean()
df.groupby('CustomerID')['Revenue'].sum().nlargest(3)
pd.merge(left, right, on='id', how='inner')
pd.read_csv(path, chunksize=10000)
scaler.fit_transform(X_train)
model.fit(X_train, y_train)
```

還要知道：`fit` 是學參數、`transform` 是套用參數；`count()` 不計缺失值、`size()` 計列數；合併鍵不唯一會增加列數；混淆矩陣、weighted F1 的分母；Python mutable default argument 可能跨呼叫保留狀態。用 [04 Python 程式閱讀攻略](./04_Python程式閱讀攻略.md) 練習追蹤具體輸出。

<a id="priority-b"></a>

## B 級：第二層，先建立用途與限制

初次安排可投入約 20% 時間，優先知道「何時用、解決什麼、不能保證什麼」。與 A 級跨章重複的概念，以 A 級的基本用法為先。

- Negative Binomial 與 Poisson 過度離散。
- Pearson、Spearman、Kendall 的差異。
- PCA 前縮放、Truncated SVD、DBSCAN 高維距離問題。
- Approximate Quantile、Quantile Regression、Box–Cox。
- 時間序列依時間切分、walk-forward validation、lag／rolling features。
- Graph Database 的節點／邊屬性與 RDF 三元組。
- Feature Store 的共用與一致性目的。
- 大批次訓練的速度與泛化取捨。
- Transformer positional encoding。
- RAG、Text-to-SQL 的適用情境。
- 同態加密、k-anonymity、差分隱私、membership inference 的核心定義。

準備到能辨識用途與適用條件即可，再依練題結果決定是否深入推導或底層實作。

<a id="priority-c"></a>

## C 級：低優先進階，時間足夠再讀

初次安排最多投入約 10% 時間。以下是偏難題庫的進階深度，並非排除在可能命題範圍之外；A 級尚未熟練時，先回補核心：

- ZINB 的完整建模判斷、Poisson 條件分佈推導、跨群合併變異的複雜計算。
- BH-FDR 手算、非劣性界值、叢集穩健標準誤、序列檢定 alpha spending。
- CDC 的 LSN／tombstone 邊界、SCD2 與 bitemporal 的完整重建。
- BRIN、quorum、write skew、Kafka transactions、watermark 精細狀態邊界。
- Spark Catalyst、salting 精確兩階段聚合、分散式 Global Top-K 證明。
- DDP sampler、FSDP／ZeRO、straggler 與完整 checkpoint 狀態。
- sequence packing mask、跨 tokenizer perplexity、來源混合 token 權重。
- 差分隱私組合預算計算、secure aggregation 與 deletion lineage 的深層實務。

不是說它們「不會考」，而是**不應在 A 級尚未穩定前投入大量時間**。

## 核心複習檢核清單

下列清單用來檢查準備是否完整；覆蓋官方 13 細項的回查入口在 [複習導航](./README.md)。

1. 基本統計圖表與 Z-score。
2. Poisson／Negative Binomial 等情境辨識。
3. t 檢定／ANOVA／p 值與型一型二錯誤。
4. 缺失、縮放、編碼與資料洩漏。
5. ACID、分片、資料湖／串流架構與資料庫選型。
6. 關聯規則、分群／降維與不平衡分類。
7. precision、recall、F1、ROC 與門檻取捨。
8. 圖表類型與避免視覺誤導。
9. AI 訓練資料規模、特徵共用、生成式 AI 查詢應用。
10. 隱私技術的用途辨識。
11. Pandas／Scikit-learn／pseudocode 閱讀與具體輸出追蹤。

## 建議練習順序

1. 先把 A 級做到能在 30～60 秒內回答。
2. 完成 [第四回真題難度校準模擬考](../regular-level/L22_第四回_真題難度校準模擬考/第四回_L22_題本_50題.md)，先記答案再看解析。
3. 依錯題細項回到 [重點總整理](./01_重點總整理.md) 查條件，用 [主動回想題](./03_主動回想題.md) 重答；公式已懂但記不牢時用 [速查表](./02_考前速查表.md)，程式卡住時用 [04](./04_Python程式閱讀攻略.md)。
4. 限時模考穩定達 80 分且能解釋錯題後，再使用偏難題庫。80 分是學習建議，不是官方及格門檻；答對但不確定的題目也要回補。

# 科目二考前高頻速查表

本表只收錄官方真題反覆出現或高度相近的核心觀念。考前先確保這些內容能快速作答，再讀進階題。

## 統計必背

| 主題 | 公式／判斷 |
|---|---|
| Z-score | `Z=(x-mean)/std`；正值在平均之上，負值在平均之下 |
| IQR | `Q3-Q1`；常見離群界線為 `Q1-1.5IQR`、`Q3+1.5IQR` |
| CDF | `F(k)=P(X≤k)`；`P(X≥k)=1-F(k-1)` |
| Precision | `TP/(TP+FP)`：預測為正者中有多少是真的 |
| Recall／TPR | `TP/(TP+FN)`：真正正例中抓到多少 |
| FPR | `FP/(FP+TN)` |
| F1 | `2×Precision×Recall/(Precision+Recall)` |
| Support | `P(A∩B)` |
| Confidence | `P(B|A)` |
| Lift | `P(B|A)/P(B)`；大於 1 為正向關聯，不代表因果 |

## 分布辨識

| 題幹 | 優先想到 |
|---|---|
| 一次成功／失敗 | Bernoulli |
| 固定 n 次試驗的成功次數 | Binomial |
| 固定時間內、獨立、穩定發生率的事件次數 | Poisson |
| 計數資料變異數明顯大於平均數 | Negative Binomial |
| 對稱鐘形連續資料 | Normal |
| 事件等待時間 | Exponential |

## 檢定選擇

| 問題 | 方法 |
|---|---|
| 一組平均數與指定值 | 單樣本 t；母體標準差已知時可用 Z |
| 兩個獨立群組平均數 | 獨立樣本 t |
| 同一批對象前後測 | 成對樣本 t |
| 三組以上平均數 | One-Way ANOVA／F |
| 兩個類別變數關聯 | 卡方獨立性檢定 |
| 兩組比例差異 | 雙比例 Z |

- `p<α`：拒絕 H0；`p≥α`：無法拒絕 H0，不是證明相同。
- Type I：H0 為真卻拒絕；Type II：H0 為假卻未拒絕。
- α 降低，第一類錯誤降低，但其他條件不變時檢定力可能下降。
- 信賴區間包含 0，雙尾 5% 檢定通常不顯著。

## 前處理一眼判斷

| 情況 | 作法／陷阱 |
|---|---|
| 右偏、有極端值 | 中位數、IQR、RobustScaler |
| 無順序類別 | One-Hot；Label Encoding 可能製造虛假順序 |
| 有順序類別 | Ordinal Encoding |
| 不同量尺 | Standardization；PCA、KNN、距離型方法尤其要注意 |
| 超大 CSV | `read_csv(chunksize=...)` 分批處理 |
| 缺失值 | 先看分布、比例與缺失機制；偏態數值可考慮中位數 |

資料洩漏口訣：**先切分，後 fit；測試資料只 transform。**

- 縮放、填補、特徵選擇、PCA、target encoding 都只在訓練資料 fit。
- SMOTE 只在訓練 fold 內做。
- 同一病人／使用者／設備以 group split。
- 預測未來以 time split，特徵不能使用未來資訊。

## 資料工程與資料庫

| 關鍵詞 | 答案方向 |
|---|---|
| 全部成功或全部回復 | Atomicity |
| 交易後符合規則 | Consistency |
| 並行交易避免不當干擾 | Isolation |
| 提交後故障仍保留 | Durability |
| 水平分散資料列 | Sharding |
| 保存相同資料副本 | Replication |
| 彈性巢狀欄位 | 文件型資料庫 |
| 關係與路徑查詢 | 圖形資料庫 |
| 高維相似搜尋 | 向量資料庫 |
| PB 級歷史資料分析 | Data Lake／欄式儲存／分散式處理 |
| Spark 巨量聚合 | executor 局部計算再彙總，不要 `collect()` 全部資料 |
| 即時 IoT | 訊息代理＋串流處理＋歷史儲存 |

## 模型與評估

- 分類預測標籤；迴歸預測連續值；分群處理未標註群組；PCA／SVD 做降維。
- K-means 要指定 k；DBSCAN 可標記雜訊，但高維時 ε 難設定。
- 極不平衡資料不能只看 accuracy。
- 不能漏掉正例：優先 recall，通常降低 threshold。
- 減少誤報：優先 precision，通常提高 threshold。
- Stratified K-Fold 維持每折類別比例。
- weighted F1 依各類別真實樣本數加權；macro F1 對每個類別等權。
- ROC 橫軸 FPR、縱軸 TPR；ROC-AUC 高不等於機率已校準。

## AI、生成式 AI 與隱私

- Feature Store：共用與版本化特徵，降低重複開發與 training-serving skew。
- Positional Encoding：為 Transformer 加入順序資訊。
- RAG：知識常更新、需附來源、需套用文件權限。
- Text-to-SQL：自然語言轉 SQL，交由資料庫精確查詢。
- 同態加密：在密文上運算。
- 差分隱私：限制單一個體對輸出的影響，提供可量化保證。
- Membership Inference：判斷某筆資料是否在訓練集中。
- 假名化仍可能再識別，不等於匿名化。

## 考場排除法

- 選項出現「保證、完全、永遠、一律」時，先檢查是否過度宣稱。
- 「使用全資料比較準」若涉及模型評估，通常是洩漏。
- 「accuracy 很高即可部署」遇到不平衡資料通常錯。
- 「資料更多會自動消除偏誤」通常錯。
- 「雜湊後一定匿名」與「聯邦學習完全隱私」都屬過度宣稱。
- 題目問總額用 `sum`，問平均用 `mean`，問筆數用 `count`。

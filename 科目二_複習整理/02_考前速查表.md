### L22101 敘述性統計與資料摘要技術

| 題目 | 公式／判斷 |
|---|---|
| 平均／中位／眾數 | 平均易受極端值影響；中位穩健；眾數可用於類別 |
| 變異數／標準差 | 變異數為平方單位，標準差同原單位；樣本變異常除 `n−1` |
| IQR／離群界線 | `Q3−Q1`；`Q1−1.5IQR`、`Q3+1.5IQR`；離群不等於必刪 |
| Z-score | `(x−mean)/std`；負值只表示低於平均，標準化不等於常態化 |
| 合併平均 | `Σ(n_i×mean_i)/Σn_i`，不能直接平均不同大小群組的均值 |
| `Y=aX+b` | 平均 `aμ+b`、標準差 `\|a\|σ`、變異數 `a²σ²` |
| P95 | 尾端分位數，不是平均或所有觀測上限 |

<a id="l22102"></a>
### L22102 機率分布與資料分布模型

| 題幹 | 分布／性質 |
|---|---|
| 一次二元結果 | Bernoulli；平均 p、變異 `p(1−p)` |
| 固定 n 次、獨立、成功率固定 | Binomial；平均 np、變異 `np(1−p)` |
| 固定區間事件數、穩定率／獨立增量 | Poisson；平均=變異=λ，λ 隨區間長度調整 |
| 計數變異遠大於平均 | 可考慮 Negative Binomial，仍先查群組與品質 |
| 連續、對稱鐘形 | Normal；68–95–99.7 規則限常態 |
| 固定率 Poisson 過程等待時間 | Exponential；rate r 時平均 `1/r` |

- `P(B|A)=P(A∩B)/P(A)`；獨立 `P(A∩B)=P(A)P(B)`；互斥 `P(A∩B)=0`。
- CDF `F(x)=P(X≤x)`；**X、k、a、b 均為整數**：`P(X≥k)=1−F(k−1)`，`P(a≤X≤b)=F(b)−F(a−1)`。
- **連續且有 PDF**：`P(X=x)=0`、`P(X≥x)=1−F(x)`；PDF 高度是密度，面積才是機率。
- Poisson 至少一次：`1−e^(−λ)`；二項常態近似看 np、n(1−p) 都足夠大。

<a id="l22103"></a>
### L22103 假設檢定與統計推論

| 問題 | 方法／條件 |
|---|---|
| 一組平均 vs 指定值 | 單樣本 t；母體標準差已知且常態／大樣本近似合理可用 Z |
| 兩獨立組平均 | 獨立 t；不宜假設等變異用 Welch（`equal_var=False`） |
| 同一人前後測 | 成對 t，看配對差值；小樣本差值需近似常態 |
| 三組以上平均 | 傳統 ANOVA：獨立、近似常態、等變異；顯著僅指至少一組不同 |
| 兩類別變數關聯 | 卡方：觀測獨立、期望次數足夠；稀疏 2×2 可考慮 Fisher |
| 兩獨立比例 | 雙比例 Z，各組成功／失敗期望數足夠 |

- p：H0 與模型成立時，統計量至少如此極端的機率，**不是 H0 為真機率**。
- `p<α` 拒絕；`p≥α` 無法拒絕，不證明相同／等效；小樣本 t 仍須看常態與獨立性。
- Type I：H0 真卻拒絕；Type II：H0 假卻未拒絕；power=`1−β`。其他條件不變，降低 α 通常降低 power。
- **匹配同一方法的雙尾 5% 檢定與 95% 區間**才對照虛無值：差值通常 **0**，比值通常 **1**。
- 獨立同分布樣本的平均標準誤約 `s/√n`；樣本多通常縮窄區間，提高信賴水準通常加寬；顯著不等於實務重要。

<a id="l22201"></a>
### L22201 數據收集與清理

| 情況 | 作法／陷阱 |
|---|---|
| 缺失／極端值 | 先查代碼、比例、機制；偏態可用中位數，不能把有效 0 當缺失 |
| 無序／有序類別 | One-Hot／Ordinal；無序數字編碼可能造成虛假順序 |
| 縮放 | Standard：非常數訓練欄位平均 0／標準差 1；Min-Max：訓練範圍常 0～1；Robust：中位／IQR |
| 新值超過訓練範圍 | Min-Max 可能超過 0～1；Standard 不保證限於某範圍 |
| 特徵選擇／衍生 | 挑原欄位／算新欄位；PCA 是轉換後降維 |

**先切分，後 fit；CV 每折亦同。** 填補、縮放、PCA、選特徵放訓練流程；SMOTE／增強只做訓練部分；target encoding 訓練列用折外統計。模型／門檻以驗證集選，測試留最後。Pipeline 不會修正未來特徵或群組切分錯誤。

### L22202 數據儲存與管理

| 關鍵詞 | 答案方向 |
|---|---|
| 全成或全敗／完整性規則 | Atomicity／Consistency |
| 並行干擾／提交後故障保存 | Isolation／Durability |
| 分散不同列／保存副本 | Sharding／Replication；分片鍵不良仍有熱點 |
| 強交易／巢狀欄位／路徑／相似 | 關聯式／文件型／圖形／向量資料庫 |
| 原始多來源／分析彙總 | Data Lake／資料倉儲 |
| 少欄歷史掃描 | Parquet 欄式＋日期分區，減少讀取 |
| left join | 留左表，但一對多可增加列數；訂單數不等於明細數 |

<a id="l22203"></a>
### L22203 數據處理技術與工具

- 定期日報：batch；低延遲事件：stream。ETL 轉換後載入，ELT 載入後轉換。
- 大 CSV：`read_csv(chunksize=...)`；`nrows` 只讀部分；最後全量合併仍可能超記憶體。
- Spark：executor 局部統計後彙總；避免 `collect()` 全量資料至 driver。
- 全局平均：`Σsum/Σ有效count`，不能直接平均各批均值。
- IoT：訊息代理／邊緣＋串流＋歷史儲存；事件 ID 去重，事件時間不等於接收時間。

<a id="l22301"></a>
### L22301 統計學在大數據中的應用

- Pearson 看線性；Spearman 看排名單調；Kendall 看一致／不一致配對；相關不等於因果。
- PCA 保留輸入變異，**不保證分類能力**；不同量尺先適當縮放。Truncated SVD 常用稀疏文字；Box–Cox 須嚴格正值。
- Quantile Regression 預測條件分位數；Approximate Quantile 快速估算資料分位數。
- 問會員就按會員抽樣；組成比例可造成辛普森反轉，資料多不自動消偏誤。
- 預測未來依時間／walk-forward；rolling 常先 shift。已排定促銷、當時預報可用，事後實際值不可用。

<a id="l22302"></a>
### L22302 常見的大數據分析方法

| 指標／方法 | 公式／條件 |
|---|---|
| 分類／迴歸／分群 | 標籤／連續值／無標籤群組 |
| K-means／KNN／DBSCAN | 群數 k／鄰居數 k／密度與雜訊；距離型注意量尺與高維 |
| Support／Confidence／Lift | `P(A∩B)`／`P(B\|A)`／`P(B\|A)/P(B)`；lift>1 不代表因果 |
| Accuracy | `(TP+TN)/全部`；不平衡不可只看此值 |
| Precision／Recall | `TP/(TP+FP)`／`TP/(TP+FN)`：警報分母／真正正例分母 |
| FPR／F1 | `FP/(FP+TN)`／`2TP/(2TP+FP+FN)` |
| MAE／MSE／RMSE | `Σ\|e\|/n`／`Σe²/n`／`√MSE`；RMSE 較放大大誤差 |

- ROC：x=FPR、y=TPR；PR：x=recall、y=precision，稀少正類尤其要看 PR。
- macro F1 各類等權；weighted F1 依真實 support 加權，可能掩蓋少數類；micro 先合併 TP／FP／FN。
- 固定分數下降門檻，recall、FPR 不減；**precision 方向不保證**。改門檻不改 ROC-AUC，嚴格遞增轉換亦保留排序。
- 門檻以驗證集選：成本 `C_FN×FN+C_FP×FP`，覆核量 `TP+FP`；AUC 高不保證校準好。
- Stratified 保類別比例，Group 保同人／設備隔離，Time 保時序；分層不能代替另外兩者。

<a id="l22303"></a>
### L22303 數據可視化工具

- 時間→折線；類別→長條；分布→histogram／box；兩連續變數→scatter；重疊→hexbin；相關矩陣→heatmap。
- 長條通常共同零基線；比較分面絕對大小用同刻度。罕見重要點另層呈現，避免抽樣漏掉。
- 不等組距直方圖：高度=`筆數/(總筆數×組距)`，面積才是比例；氣泡面積 4 倍→半徑 2 倍。
- 比率比較看分母／區間；少裝飾、清楚標籤與單位。

<a id="l22401"></a>
### L22401 大數據與機器學習

- 更多資料不保證品質；資料增強須保留標籤，原圖與增強版本不可跨訓練／測試。
- 資料平行 global batch=`每裝置 batch×裝置數×累積步數`；大批次不保證泛化提升。
- Feature Store 共用與版本化特徵，降低訓練／服務不一致；GPU 等資料先查載入。
- 資料漂移 `P(X)` 改變不等於概念漂移 `P(Y|X)` 或已證明效能下降。

<a id="l22402"></a>
### L22402 大數據在鑑別式 AI 中的應用

- 鑑別式建模 `P(Y|X)`／邊界；Logistic Regression 做分類，Linear Regression 做迴歸。
- 生成式分類可由 `P(X|Y)P(Y)` 推得結果；有標籤／輸出機率不決定模型類型。
- 決策樹 Gini=`1−Σp²`，子節點依樣本數加權；KNN 等權票數與距離加權結果可不同。

<a id="l22403"></a>
### L22403 大數據在生成式 AI 中的應用

- 位置表示→順序；padding mask→排除補齊；causal mask→不能看未來 token。
- RAG→更新知識、引用；**檢索前／時控權限**，不保證無幻覺；rerank 改善候選排序。
- 微調→行為／格式／能力；Text-to-SQL→資料庫精確執行，但需驗證指標、粒度與關聯。

<a id="l22404"></a>
### L22404 大數據隱私保護、安全與合規

- 雜湊／假名化仍可再識別；k-anonymity 保準識別組至少 k 筆，不保證敏感值多樣。
- 同態加密→密文運算；差分隱私→限制單人影響、可量化保證，仍有預算／效用取捨。
- 聯邦學習不自動完全隱私；安全聚合依協定假設保個別更新；Membership Inference 判斷訓練成員。
- 技術不取代合法利用依據、目的限制、最小化、存取控制與稽核。

## 程式語法最後回查

`sum` 加總，`mean` 略缺失平均，`count` 非缺失數，`size` 列數；`agg` 群組結果，`transform` 對齊原列；`inner` 共同鍵但不自動去重；`'Int64'` 缺失整數；`fit` 學參數、`transform` 套參數。可變預設參數跨呼叫共用，淺複製內層仍共用。

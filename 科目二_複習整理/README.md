## 一條主線記全科

遇到情境題，依序問：

1. **目標是什麼？** 描述、推論、預測、因果、低延遲，還是可追溯？
2. **時間對嗎？** 特徵在預測當下是否可得？事件時間與處理時間是否混用？
3. **切分對嗎？** 同一病人、設備、文件家族是否跨到訓練與測試？
4. **分母對嗎？** 比率有沒有母體分母？macro、micro、weighted 的權重是什麼？
5. **獨立單位對嗎？** 100 張同病人影像不等於 100 個獨立病人。
6. **規模對嗎？** 方法能否處理資料量、延遲、記憶體與網路成本？
7. **保證邊界是什麼？** 「降低風險」不等於「完全保證」；假名化不等於匿名化。

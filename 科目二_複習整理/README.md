# AI 應用規劃師中級｜科目二複習導航

科目二為 **L22 大數據處理分析與應用**，含 4 大主題、13 個細項。本整理以 repository 內的 115.06 官方評鑑範圍、115 年簡章及既有題庫為基礎，承接既有整理對 114 年第二次、115 年第一次公告試題的人工判讀。

**使用順序：診斷弱點 → 回查概念 → 遮住答案重答 → 限時模考 → 訂正與複驗。** 每讀完一個細項，就做對應回想題；能說出理由與適用條件，才進入下一項。

## 情境題的判讀順序

1. **目標與資料型態：**描述、推論、預測、查詢還是生成？資料是數值、類別、計數還是時間序列？
2. **分析單位與切分：**兩組是否獨立、是否前後配對？同病人／設備要不要隔開？是否預測未來？
3. **資訊可得時間：**預測當下能取得該特徵嗎？前處理有沒有用到驗證／測試資料？
4. **分母與成本：**按筆數、群組或類別加權？漏報與誤報哪個成本高？
5. **規模與保證邊界：**記憶體、延遲、資料權限是否符合需求？方法是否只能降低風險？

## 錯題紀錄與複驗

每次訂正寫出：**正解成立的條件**、**最像答案的干擾項為何不成立**，再遮住解析重答。隔 1、3、7 天重答可作為起點；答錯就提早再練，熟練則拉長間隔。

| 日期 | 來源／題號／細項 | 錯因 | 正確規則與條件 | 干擾項問題 | 複驗日／結果 |
|---|---|---|---|---|---|
| 範例 | 第六回／21／L22203 | 分母 | 全體均值＝局部總和相加／有效筆數相加 | 群組筆數不同，不能直接平均各群均值 | 隔 1 天／能重算並解釋 |
|  |  | 觀念／計算／程式／條件／粗心 |  |  |  |

自評 `A`＝能完整解釋與指出陷阱；`B`＝方向正確但條件不完整；`C`＝答錯或說不出理由。B／C 題依上表直達 01 回補，再回到 03 重答。

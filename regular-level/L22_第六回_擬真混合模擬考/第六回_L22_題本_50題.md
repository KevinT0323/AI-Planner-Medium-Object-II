### 第 6 題

決策樹在同一父節點比較兩個候選分割，以各子節點樣本數加權後的 Gini 不純度越低越好。每個括號表示該子節點中「類別 0、類別 1」的件數。甲分成 (4,1)、(2,3)，乙分成 (6,2)、(0,2)。依下列定義，何者正確？

```python
def gini(n0, n1):
    n = n0 + n1
    return 1 - (n0 / n) ** 2 - (n1 / n) ** 2

def score(children):
    total = sum(a + b for a, b in children)
    return sum((a + b) / total * gini(a, b) for a, b in children)
```

(A) 甲為 0.20、乙為 0.30，選甲

(B) 甲為 0.40、乙為 0.30，選乙

(C) 甲為 0.40、乙為 0.1875，選乙

(D) 甲與乙均為 0.48，兩者無法區分

<details>
<summary>查看答案與解析</summary>

**答案：B**

**考點：**L22402｜中等

**解析：**甲兩子節點的 Gini 為 0.32、0.48，樣本數各 5，故加權為 0.40。乙兩子節點為 0.375、0，權重為 0.8、0.2，故加權為 0.30；在相同父節點下，乙的下降量較大。

**其他選項：**

- A：甲的正確加權值為 0.40，不是 0.20，不能再多除一次子節點數。
- C：0.1875 是乙兩子節點 Gini 的未加權平均，忽略 8 筆與 2 筆的大小差異。
- D：0.48 是共同父節點的 Gini＝1−0.6²−0.4²，不是分割後的加權值。

</details>

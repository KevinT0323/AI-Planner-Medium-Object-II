```python
import pandas as pd
import numpy as np

raw = pd.DataFrame({
    "value": ["68", "86", "bad", "50", "-4"],
    "unit": ["F", "F", "C", "F", "F"]
})

x = pd.to_numeric(raw["value"], errors="coerce")
celsius = x.copy()
is_f = raw["unit"].eq("F")
celsius.loc[is_f] = (x.loc[is_f] - 32) * 5 / 9

valid = celsius.where(celsius.between(-10, 50)).dropna()
n = len(valid)
sd = float(valid.std(ddof=1))
se = sd / np.sqrt(n)

print(n, round(float(valid.mean()), 1))

```

### 第 12 題

**程式閱讀題**

風險團隊只使用驗證集選門檻，規定每批最多覆核三件。每漏掉一個正例成本為 4，每個誤報成本為 1；在符合覆核上限的候選中，選總成本最低者。以下 s 為正類分數，程式會輸出「門檻、成本、覆核件數」。

```python
import numpy as np

y = np.array([1, 1, 1, 0, 0, 0, 0, 0])
s = np.array([0.9, 0.7, 0.4, 0.8, 0.6, 0.3, 0.2, 0.1])
candidates = [0.35, 0.65, 0.85]
feasible = []

for threshold in candidates:
    pred = s >= threshold
    fp = int(((y == 0) & pred).sum())
    fn = int(((y == 1) & ~pred).sum())
    review_count = int(pred.sum())
    cost = fp + 4 * fn
    if review_count <= 3:
        feasible.append((cost, threshold, review_count))

best = min(feasible)
print(best[1], best[0], best[2])
```

(A) 0.35 2 5

(B) 0.85 8 1

(C) 0.65 1 3

(D) 0.65 5 3

**答案：D**

**考點：**L22402｜大數據在鑑別式 AI 中的應用

0.35 雖成本低，覆核五件而不符合限制。0.65 有一個 FP、一個 FN，成本為 5，覆核三件；0.85 成本為 8，因此選 0.65。

### 第 45 題

```python
from collections import defaultdict

vector_rank = ["D3", "D1", "D5", "D2"]
allowed = {"D1", "D2", "D4", "D5"}
scores = defaultdict(float)

for ranked in [keyword_rank, vector_rank]:
    for rank, doc in enumerate(ranked, start=1):
        if doc not in allowed:
            continue
        scores[doc] += 1 / (10 + rank)

chosen = sorted(scores, key=lambda doc: (-scores[doc], doc))[:2]
print(chosen)
print("D3" in scores)
```

(A) ['D3', 'D1']；True

(B) ['D1', 'D5']；False

(D) ['D1', 'D2']；False

D3 未授權，直接跳過。D1 得分約 0.1742，D2 約 0.1548，皆高於其餘授權文件。程式使用原始名次，跳過 D3 不會重新編排該排序的名次。

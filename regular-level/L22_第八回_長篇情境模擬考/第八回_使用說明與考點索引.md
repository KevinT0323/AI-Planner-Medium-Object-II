# 第八回｜使用說明與考點索引

## 作答方式

[開啟第八回 50 題題本](./第八回_L22_題本_50題.md)。本回以較長情境、整合條件與完整程式流程練習判讀；題數與配置屬學習設計，非官方配分或命題預測。

1. 建議連續限時 90 分鐘，先保持 50 組答案解析收合。
2. 每題選一個最適當答案，本模擬卷每題 2 分；組合題須選正確的完整組合，不另給部分分數。
3. 作答時記錄信心，完成後再逐題展開答案與解析。
4. 對錯題與猜對題寫出判斷條件，依下表回查；程式題先列中間資料，再核對輸出。

## 題型配置

- 敘述組合題共 **10 題**：1、4、8、10、14、15、19、22、36、46。
- Python 程式閱讀共 **12 題**：3、7、12、16、20、24、29、33、37、41、45、49。
- 其餘 **28 題**為情境與計算判斷；全部外層均為單選。
- 程式包含清理與去重、單位換算、標準誤、門檻成本、ColumnTransformer、母體加權、貢獻裁剪、SQLite 交易、密度直方圖、多類別指標、Welch t 檢定、檢索排序與準識別泛化。

## 訂正與複驗

- 觀念題：說明方法的適用條件及保證範圍。
- 組合題：逐條判斷①～④，寫出錯誤敘述的問題，避免只背組合字母。
- 計算題：先列分析單位、分母與權重，再重算。
- 程式題：追蹤每一步的列數、型別、缺失處理、鍵與學參數的資料範圍。
- 隔一段時間保持答案收合重答，確認能說出理由；成績用於安排回補，不推定正式考試分數。
